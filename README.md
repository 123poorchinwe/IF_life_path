# IF人生线：未开放区域

《IF人生线：未开放区域》是一款面向毕业生与职业转型者的AI职业决策模拟器。它不会通过性格测试替用户选择“最适合的职业”，而是把用户的真实经历拆解成能力、资格、证据与限制，再通过职业地图和情景互动帮助用户看清不同选择的进入条件、机会成本与风险。

> 你看见的职业，只是当前能够识别的部分。

## 产品目标

用户完成一次体验后，应能够回答：

- 我当前有哪些真实可进入的职业路径？
- 哪些路径只缺少一两项可以补足的条件？
- 哪些岗位存在专业、学历、身份或时间窗口等硬门槛？
- 我的项目经历可以迁移到哪些相邻行业？
- 我对稳定、收入、自主、成长与风险的取舍是什么？
- 下一步可以进行哪些低成本、可验证的现实实验？

产品不承诺录取、Offer或考试结果，不提供虚假的职业匹配百分比，也不会把模糊的“相关专业”自动解释为符合资格。

## 当前MVP

项目已经实现一条可本地运行的体验闭环：

```text
建立档案 → AI卡牌确认 → 职业地图 → 情景模拟
        → 能力重组 → 职业结论
```

目前包含：

- GIS硕士预设档案与文本建档入口；
- 事实、推断、能力、资格、限制和偏好卡片；
- 30个职业节点及不同职业门状态；
- 职业关系网络与像素区域地图；
- Phaser实时2D地图底座；
- 玩家移动、镜头跟随、碰撞和NPC巡逻；
- 建筑入口、室内场景与NPC自由输入对话；
- 8类核心NPC人物设定；
- 40个结构化事件骨架；
- 六阶段时间与资源状态；
- 能力迁移和职业结论页面；
- ModelScope对话接口与本地回退；
- 桌面端和移动端响应式布局。

## 职业门状态

系统不用单一匹配分数，而是显示可解释状态：

| 状态 | 含义 |
| --- | --- |
| 已开放 | 当前具备主要进入条件，可以开始投递或进一步核验 |
| 接近开放 | 缺少一至两项可补条件，例如SQL、作品或行业案例 |
| 需要调查 | 招聘表述或专业要求存在歧义，不能由AI直接下结论 |
| 硬性受限 | 存在明确的专业、学历、身份、年限或资格门槛 |
| 时间敏感 | 受到秋招、考试、申请或应届身份窗口影响 |
| 新发现 | 能力迁移关系成立，但仍需要现实岗位证据支持 |

## AI与规则的边界

项目严格区分三层：

1. **规则层**：计算职业硬门槛、时间、精力、资金、信息质量和关系变化。
2. **AI层**：负责档案解析、能力迁移解释、NPC自然对话和情景表达。
3. **表现层**：负责职业网络、像素地图、室内场景、证据标签和结果报告。

AI不能直接修改游戏数值、资格条件或职业门状态。模型输出需要经过Zod校验，后果只能以语义标签进入确定性规则引擎。

## NPC设计

NPC不是简单的好人或坏人。每个人具有稳定的：

- 身份与经历；
- 职责与可用资源；
- 当前目标和组织压力；
- 知识范围与信息盲区；
- 说话方式和压力反应；
- 利益一致程度和权力差；
- 对玩家互动的连续记忆。

AI负责实时生成自然语言，但必须遵守人物设定。NPC可以犹豫、误解、反问、改口或拒绝回答，却不能突然改变核心经历、价值倾向或凭空知道职责之外的信息。

## 本地运行

要求：

- Node.js 20.19或更高版本；
- npm 10或更高版本。

安装并启动：

```bash
npm install
npm run dev
```

浏览器访问：

```text
http://localhost:3000
```

常用命令：

```bash
npm run dev        # 启动开发服务器
npm run typecheck  # TypeScript检查
npm run lint       # ESLint检查
npm run build      # 生产构建
npm run start      # 启动生产服务器
```

## 配置AI对话

复制环境变量模板：

```powershell
Copy-Item .env.example .env.local
```

在`.env.local`中配置：

```env
AI_PROVIDER=modelscope
AI_BASE_URL=https://api-inference.modelscope.cn/v1
AI_MODEL=Qwen/Qwen2.5-72B-Instruct
MODELSCOPE_ACCESS_TOKEN=你的服务端Token
```

重新运行`npm run dev`。接口成功时，NPC对话会显示AI在线；密钥缺失、网络异常或模型输出校验失败时，系统会切换到本地回退，不阻断主要流程。

### 安全说明

- `.env.local`不会提交到Git；
- Token只在服务端API路由中读取；
- 浏览器端不会获得服务端Token；
- 不要把真实密钥写入README、源码或`.env.example`；
- 如果密钥曾经出现在聊天、截图或公开提交中，请立即轮换。

## 数据与内容说明

当前职业和岗位内容主要用于MVP交互验证，不构成现实招聘建议。正式使用前需要：

- 接入可追溯的官方招聘公告与授权数据来源；
- 保存原始岗位文本、来源链接、发布日期和截止日期；
- 对专业目录、应届身份、证书和工作年限进行逐岗核验；
- 区分官方证据、多个来源、单一经验和AI推断；
- 对已过期岗位进行自动标记和复核。

## 当前限制

- ModelScope在部分网络环境下可能出现连接重置或超时；
- 像素人物仍使用程序生成的临时精灵，尚未接入正式四方向Sprite Sheet；
- 地图碰撞区域目前为手工配置，尚未使用Tiled瓦片碰撞层；
- NPC巡逻已接入Phaser，但完整日程和长期记忆仍在开发；
- 岗位数据尚未接入正式抓取或授权数据源；
- Supabase持久化与账号系统暂未接入。
